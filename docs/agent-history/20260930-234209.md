**LithosAI経由でOpenCodeを動かせます。公式にOpenCode専用の接続手順があり、直接接続できます。** [公式ガイド](https://docs.lithosai.com/agent-integrations/opencode)

手元を確認したところ、OpenCode **1.18.34** は導入済みです。グローバル設定にはまだLithosAIの設定がありません。

接続に使う値は次のとおりです。

| 項目 | 設定 |
|---|---|
| 接続先 | `https://api.lithosai.cloud/v1` |
| OpenCodeのアダプター | `@ai-sdk/openai-compatible`（同梱済み） |
| APIキー | 環境変数 `LITHOSAI_API_KEY` |
| DeepSeekのモデルID | **Lithosの管理画面で確認が必要** |

設定例は以下です。既存の `~/.config/opencode/opencode.jsonc` に追加します。`MODEL_ID` は[Models画面](https://console.lithosai.cloud/models)に表示された正確なIDへ置き換えます。ZenやDeepSeek公式のIDを流用できるとは限りません。

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "lithosai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "LithosAI",
      "options": {
        "baseURL": "https://api.lithosai.cloud/v1",
        "apiKey": "{env:LITHOSAI_API_KEY}"
      },
      "models": {
        "MODEL_ID": {
          "name": "DeepSeek V4.1 Flash (Lithos)"
        }
      }
    }
  }
}
```

APIキーを環境変数に設定したシェルから、次で起動します。

```bash
opencode --model lithosai/MODEL_ID
```

実用上、**コンテキスト長・最大出力長・reasoning対応もModels画面に合わせる**必要があります。公式ガイドの最小構成はテキストとツール呼び出し用で、これらの能力や上限は自動取得されません。[設定上の注意](https://docs.lithosai.com/agent-integrations)

DeepSeek V4.1 Flashは、現在の早期割引表示で以下の料金です。速度はLithosの公称値です。[料金表](https://www.lithosai.com/pricing)

| プラン | 速度 | 入力／出力料金（100万token） |
|---|---:|---:|
