2. **HTTP・SQLのソートと詳細表示**
   
   合計時間だけでなく、回数・平均・p95などから並べ替え、行を選ぶと詳細を開けるようにします。「回数が多い」のか「1回が遅い」のかを人間が判断しやすくなります。
